# Multi-Agent Research System

A professional parallel orchestration system built using Python to generate comprehensive, cited research reports.

## 🚀 Key Features
* **Parallel Subagents**: Runs specialized workers simultaneously to maximize performance.
* **Strict Fact Provenance**: Tracks claims back to exact source URLs and text excerpts.
* **Resilient Error Propagation**: One subagent crashing does not kill the entire research run.
